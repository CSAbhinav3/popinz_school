# How to run the Play School app

## Option 1: Two terminals (recommended)

### Terminal 1 – Backend
```bash
cd "d:\Semester 6\SL_Project\preschool-app - Copy\backend"
python run.py
```
Wait until you see: **Application startup complete.**

### Terminal 2 – Frontend
```bash
cd "d:\Semester 6\SL_Project\preschool-app - Copy"
npm install
npm run dev
```

### Open the website
In your browser go to: **http://localhost:5173**

---

## Option 2: Double‑click (Windows)

1. Double‑click **start-backend.bat** (starts the API).
2. Double‑click **start-frontend.bat** (starts the website).
3. Open **http://localhost:5173** in your browser.

Keep both command windows open while using the app.
